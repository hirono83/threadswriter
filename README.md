# threadswriter

[@kwz_note](https://www.threads.com/@kwz_note) 계정의 문체를 분석하고, 방향성을 유지하며
매일 3개의 주제·초안을 생성하기 위한 저장소입니다.

- `style-guide.md`: 계정 분석 결과 및 문체 가이드
- `drafts/`: 날짜별 3개 주제 + 초안

## 파일 구성

| 파일 | 관리 주체 | 용도 |
|---|---|---|
| `style-guide.md` | AI (사용자 수정 환영) | 문체·구조 패턴·글의 목표·품질 기준 |
| `experience-pool.md` | **사용자** | IB 경험·실패담·본인 원칙·육아 장면. 여기 있는 것만 "내 경험"으로 씁니다 |
| `idea-bank.md` | AI | 기업·산업 구조 소재, 책·주주서한 인용 후보를 미리 비축 |
| `edit-log.md` | AI | 원본 초안 vs 실제 게시본의 차이를 비교·축적해서 편집 패턴을 학습 |
| `drafts/YYYY-MM-DD.md` | AI 생성 / 사용자 기록 | 날짜별 초안 3편 + "성과 기록"란 + 편별 "최종 게시본"란 |

## 매일 돌아가는 흐름

1. 매일 07:00 KST 자동 실행
2. 스타일 가이드 → 경험 풀 → 아이디어 저장고 → 최근 성과 기록·최종 게시본 →
   edit-log 순으로 읽기
3. 최종 게시본이 원본과 다른 게 있으면 diff를 떠서 edit-log에 기록 (같은
   종류가 3회 반복되면 누적 패턴 → style-guide 규칙으로 승격)
4. 소재 우선순위: 본인 경험 > 기업·산업 분석/책 인용 > 오늘 시황
5. 초안 3편 작성 후 품질 게이트 5개 항목 자체 채점, 미달 시 재작성
6. 커밋·푸시 → Obsidian에서 pull

## 사용자가 할 일

- **`experience-pool.md` 채우기** — 떠오를 때마다 한 줄씩. 가장 큰 차별화 요소입니다.
- **초안 파일의 "성과 기록"란 채우기** — 게시 여부와 반응, 특히 메모.
- **수정해서 게시했다면 "최종 게시본"란에 실제로 올린 전문을 붙여넣기** —
  가장 강력한 학습 신호입니다. 정확히 뭘 고쳤는지 매일 비교해서 배웁니다.
